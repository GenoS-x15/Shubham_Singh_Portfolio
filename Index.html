Infosage: Website Footprinting Toolkit

May 2025 – Jul 2025 · Python · Kali Linux

A modular, menu-driven reconnaissance tool that automates the first stage of a penetration test. It checks connectivity and required tools, installs anything missing, runs the scans with live progress bars, and saves every result into an organised footprint_results folder. Run it with python3 Infosage.py <target-domain>.

  • Automates about 95% of footprinting tasks and pulls 100+ subdomains, emails, IPs and DNS records per scan.
  • Combines WHOIS, DNS and host IP resolution, email enumeration, subdomain enumeration and an Nmap basic scan, or runs all of them as one automated pass.
  • Colour-coded output, auto-installation of missing tools and result logging make it dependable across setups.
  • Tested on Kali Linux in red team simulations.
